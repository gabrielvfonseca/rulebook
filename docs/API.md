# API

Agent Config exposes a machine-graded registry of agent configuration files.

## Registry item

Each entry lives under `registry/items/<slug>/` with two files:

- `item.json` — metadata and provenance
- `content.md` — the canonical agent config content

### `item.json` fields

| Field              | Type                              | Description                                                                   |
| ------------------ | --------------------------------- | ----------------------------------------------------------------------------- |
| `name`             | string                            | URL-safe slug; also the CLI install name                                      |
| `type`             | `"registry:file"`                 | registry item type                                                            |
| `title`            | string                            | human-readable title                                                          |
| `description`      | string                            | short description                                                             |
| `files`            | array                             | generated by `build:registry`; one entry per agent target                     |
| `registry.stack`   | string[]                          | tech-stack tags                                                               |
| `registry.agents`  | string[]                          | target agents                                                                 |
| `registry.grade`   | `"A" \| "B" \| "C" \| "ungraded"` | letter grade                                                                  |
| `registry.score`   | number \| null                    | machine rubric score (0-100)                                                  |
| `registry.note`    | string                            | editorial one-liner                                                           |
| `registry.source`  | object                            | provenance (`kind`, `repo`, `path`, `commit`, `commitDate`, `license`, `url`) |
| `registry.added`   | string                            | ISO date added                                                                |
| `registry.version` | string                            | semver                                                                        |

## Generated artifacts

Running `pnpm build:registry` produces:

- `registry/index.json` — full manifest (`RegistryIndex`)
- `registry/r/<name>.json` — shadcn-style per-item endpoint
- `README.md` — generated docs with entry table

## Rubric scores

Curated entries are scored 0-100 across six dimensions:

- **Brevity** (20) — ≤200 lines and ≤4,000 tokens
- **Structure** (20) — overview, commands, architecture, rules sections
- **Testability** (20) — concrete, copy-pasteable test command
- **Actionable density** (20) — ≥40% imperative/concrete lines
- **Freshness** (10) — source commit within 180 days
- **Dedupe** (10) — not byte-identical to another entry

Grades: A ≥ 85 · B ≥ 70 · C ≥ 50 · below = not published.

## CLI programmatic API

The CLI is a Node.js ESM binary at `dist/cli.js`. It is not published as a
library; use the `agent-config` command or the shadcn-compatible registry
endpoints directly.
